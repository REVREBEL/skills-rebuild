# Skills Create, Manage, and Update

A master skill suite for managing the full lifecycle of skills in the skill library. This master skill coordinates specialized sub-skills to ensure consistent, high-quality skill authoring, evaluation, and maintenance.

## When to Use

Use this skill when the user wants to:
- Create a new skill from scratch or from conversation context
- Audit, review, or validate existing skills against quality standards
- Improve, optimize, or re-write skill instructions and descriptions
- Inventory, check, or restructure skills in the skill library
- Template or standardize skill authoring workflows

## Included Sub-Skills

This master suite includes the following specialized sub-skills:

1. **skill-creator**: Creates new skills from scratch, conversation context, or user requirements.
2. **skill-writer**: Authors and drafts detailed, high-quality skill files and documentation.
3. **skill-audit**: Conducts comprehensive audits of skill libraries and individual skills.
4. **skill-check**: Validates skill structure, frontmatter metadata, and formatting rules.
5. **skill-improver**: Refines and enhances instruction clarity, triggers, and examples.
6. **skill-inventory**: Catalogues and lists all available skills and metadata across the library.
7. **skill-library-restructure**: Reorganizes, merges, or splits skill taxonomies and folder structures.
8. **skill-make-template**: Generates standardized skill templates for rapid authoring.
9. **skill-manage**: Handles ongoing maintenance, enabling, disabling, and lifecycle updates.
10. **skill-optimizer**: Optimizes skill descriptions for precise LLM trigger activation and token economy.
11. **skill-review**: Performs peer review and quality evaluation on drafted skills.
12. **skills-writing**: Enforces writing principles, patterns, and best practices for skill instructions.
13. **template-skill-enhanced**: Provides enhanced reference templates and validation rubrics.

## Workflow Execution

1. **Identify User Intent**: Determine whether the user needs to create, audit, improve, check, or restructure skills.
2. **Route to Sub-Skill**: Activate the corresponding sub-skill from the suite to execute the specialized workflow.
3. **Validate & Persist**: Run structural checks using  or  prior to saving or updating skills.
